# 🌤 SkyPulse — Weather & Air Quality Dashboard

A real-time **Weather & Air Quality Dashboard** built with pure HTML, CSS, and JavaScript using the OpenWeatherMap API.

## 🔗 Live Demo
> [Click here to view the live site](https://YOUR-USERNAME.github.io/weather-dashboard)

---

## ✨ Features

- 🔍 Search weather for **any city** worldwide
- 📍 **GPS-based location detection**
- 🌡 Current temperature, feels like, humidity, wind, pressure, visibility
- 🌅 Sunrise & Sunset times
- 🫧 **Air Quality Index (AQI)** with color-coded indicator
- 🧪 6 pollutant readings — PM2.5, PM10, CO, NO₂, O₃, SO₂
- 📅 **5-Day Forecast** with min/max temperatures
- 🕐 **Hourly Forecast** (24 hours, scrollable)
- 💾 API key saved in browser — no re-entry needed
- 📱 Fully **responsive** — works on mobile, tablet, desktop

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone git@github.com:YOUR-USERNAME/weather-dashboard.git
cd weather-dashboard
```

### 2. Get a free API Key
- Sign up at [openweathermap.org](https://openweathermap.org)
- Go to **Profile → API Keys**
- Copy your key

> ⚠️ New API keys take up to **2 hours** to activate after signup.

### 3. Open the app
Just open `index.html` in your browser — no build step needed!

On first launch, a modal will ask for your API key. Paste it and click **Save & Continue**.
